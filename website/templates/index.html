Worlds with a history, built where your data lives

Everything runs on your machine — no cloud dependency, no telemetry, nothing uploaded.

A world is a package

A .world is a folder: the world now, the log of every change ever made to it, and its assets by content hash. The state at any revision is a fold of the log, so undo, branches, replay and sharing are reads over one history — the Open World Format, which any viewer of the format opens.

Agents edit from outside

Open a package as a live canvas and no agent runs in the window. Claude Code, Codex, a script or localgpt itself sends a batch of ops to the folder's local API; it commits whole or is refused with a reason per op. Review each batch before it lands, if you like. Learn more →

One desktop app

A prompt, a Markdown document, a song or a package — each opens as a world in the same window. A document rebuilds in place as you type while the model authors each section's place; a song's analysis picks and performs its world with no model at all. Learn more →

Script to board

Drop a screenplay — PDF, Final Draft, Fountain or Markdown — on localgpt.md and get a previs board in the tab: a set, stand-ins and coverage per scene with real lenses and measured cameras. Then revise the shots by asking, and compare treatments as branches. Learn more →

Build together

Host a world; friends join from their own window or a browser with the invite link, walk the same world live, and ask your AI to build where they're looking. A relay reaches guests beyond the LAN. Every session is a package with per-user undo and replay. Learn more →

Behaviors and procedural audio

Animate without scripting — orbit, spin, bob, look-at, pulse, path-follow, bounce — and add ambient soundscapes and spatial emitters synthesized in real time. Song worlds bind entity parameters to the music's energy, beat and stems.

MCP in both directions

localgpt-gen mcp-server lets Claude Desktop, Claude Code, Codex, Gemini CLI and editors drive the 3D window; localgpt world mcp serves an open canvas's tools to any agent; localgpt mcp-server offers memory and web tools; and the assistant consumes external MCP servers too.

Memory that persists, work that runs unattended

A Markdown workspace with hybrid search — SQLite FTS5 plus local embeddings — recalled before each reply and consolidated in the background. A heartbeat and cron jobs do scheduled work with a durable outbox. Learn more →

Local & private

Single Rust binaries, your choice of model — Claude, Gemini and Codex CLIs, Anthropic, OpenAI, Ollama, GLM, or a GGUF running in-process — behind a kernel-enforced shell sandbox and standing instructions the agent cannot rewrite. Learn more →

An open standard for spatial computing.

Most AI world-generation platforms isolate experiences inside proprietary cloud servers and closed walled gardens. LocalGPT takes the opposite stance: your machine generates the meshes, compiles the shaders, and simulates the physics.

localgpt.world serves as the umbrella portal where standalone world formats converge. Whether born from a single paragraph prompt, an outline in a Markdown document, or a symphonic track, worlds are represented in portable, open formats.

Get Started via Cargo / Source 
# 1. Install LocalGPT Gen to generate 3D worlds from prompts
cargo install localgpt-gen

# 2. Or run LocalGPT MD to explore markdown documents as spaces
git clone https://github.com/localgpt-app/localgpt-md.git
cd localgpt-md && cargo run -- path/to/notes.md

# 3. Or launch LocalGPT Verse to turn songs into living worlds
git clone https://github.com/localgpt-app/localgpt-verse.git
cd localgpt-verse && cargo run

The same file, as a world

Each ## heading becomes a place along a path. Longer sections grow taller landmarks. Arrow keys fly you from one to the next.

How it works

1. Open any Markdown

Notes, a story, a talk. Each ## heading becomes a place, and the text stays beside you as you walk.

2. Walk it

Arrow keys move from section to section. Worlds use LocalGPT's world format, the same one LocalGPT Gen saves.

3. Save to rebuild

Keep the file open in your editor. Each save rebuilds the world, and sections you didn't touch stay exactly as they were.

Coming next: an agent tier: the model builds each section through tool calls and fills it with real 3D assets from the shared pack — still local, your notes never leaving your computer.

Slides already become 3D talks (try cargo run -- samples/deck.md). Later: scripts become blocked-out scenes, journals become worlds that grow.
